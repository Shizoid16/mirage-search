# Mirage — разбор ситуаций по кодексу без ИИ и без денег
Чистая статика: умный поиск (синонимы, опечатки, намерения) + шаблонный разбор ситуации.

## Локально
Открыть index.html или: python -m http.server

## Обновить кодекс
Правь js/data.js напрямую (или codes/*.md + python tools/build_index.py).
