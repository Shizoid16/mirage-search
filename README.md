MIRAGE — подключение регистрации, базы и избранного

Что добавлено в index.html
- Раздел «Аккаунт»: регистрация по email и паролю, вход и выход.
- Профиль пользователя с изменяемым именем.
- Раздел «Избранное»: звёздочка на карточках статей, сохранение и удаление.
- Избранное привязано к аккаунту и загружается после входа на любом устройстве.
- Настройки оформления и сохранённые стили синхронизируются с профилем.
- Без подключения базы текущий каталог законов и локальное оформление продолжают работать.

1. Создайте проект Supabase
Откройте https://supabase.com/ и создайте новый проект. Сохраните пароль базы данных в надёжном месте.

2. Создайте таблицы и политики безопасности
В панели проекта откройте SQL Editor → New query. Скопируйте весь файл supabase_schema.sql, вставьте его и нажмите Run.
Скрипт создаёт таблицы profiles и favorites, автоматическое создание профиля при регистрации и политики Row Level Security.

3. Укажите ключи проекта
В Supabase откройте Project Settings → API (или Connect / API Keys — название раздела может отличаться).
Скопируйте Project URL и публичный ключ anon / publishable.
В начале второго script-блока index.html найдите:

  const SUPABASE_URL = "https://YOUR_PROJECT_ID.supabase.co";
  const SUPABASE_ANON_KEY = "YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY";

Замените значения своими. В браузерный файл разрешено помещать только публичный anon/publishable key.
НИКОГДА не вставляйте сюда service_role / secret key — он обходит ограничения доступа к данным.

4. Настройте подтверждение почты
В Supabase → Authentication → URL Configuration укажите адрес размещённого сайта в Site URL.
Добавьте этот же адрес в Redirect URLs, если используете список разрешённых адресов.
Для тестов можно отключить Confirm email в настройках Auth, тогда регистрация сможет сразу создавать сессию. Для публичного сайта подтверждение email лучше оставить включённым.

5. Разместите сайт
Загрузите index.html на статический хостинг (например, GitHub Pages, Netlify или Cloudflare Pages). Отдельный сервер для этой версии не нужен: аутентификацию и запросы к PostgreSQL обслуживает Supabase.
Открывать сайт локально через file:// для полноценной регистрации не рекомендуется; используйте локальный HTTP-сервер или опубликованный HTTPS-адрес.

Проверка
1. Откройте сайт и перейдите в «Аккаунт».
2. Зарегистрируйте тестового пользователя и подтвердите email, если это включено.
3. Добавьте несколько законов в избранное.
4. Перезагрузите сайт или войдите с другого браузера — список должен загрузиться из базы.
5. Измените тему/цвет в «Дизайн» — настройки профиля должны сохраниться после следующего входа.

Примечания по безопасности
- Не отключайте RLS для таблиц profiles и favorites.
- Не публикуйте пароль базы, service_role key или секретные ключи.
- Перед публичным запуском добавьте CAPTCHA / rate limits для регистрации и настройте SMTP-провайдера для писем подтверждения.
- Статьи и тексты законов остаются в index.html; в базе хранятся только аккаунты, настройки и идентификаторы избранных статей.
